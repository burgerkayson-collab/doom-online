#### DOOM Online (Complete Crispy Doom Web Port)

A complete, single-file WebAssembly/JavaScript port of **Crispy Doom** that runs classic DOOM and custom mods directly in a modern web browser with no installation required. 

🌐 **Play Online:** [https://doom-online.js.org](https://doom-online.js.org) *(Netlify Mirror: [https://doom-online.netlify.app](https://doom-online.netlify.app))* 

#### Features

* Complete Crispy Doom engine running 100% client-side via WebAssembly & WebGL/Canvas
* Load your own local **IWADs** (doom.wad, doom2.wad, freedoom1.wad, etc.) and **PWAD mods** directly in the browser
* Self-contained, single-file index.html build with zero external dependencies
* Full keyboard, mouse, and audio support

#### Game Data & Copyright Notice

This project **does not** host or distribute any copyrighted game assets. Users supply their own legally owned IWADs and custom PWAD mods locally in their browser, and all files are processed strictly client-side.
